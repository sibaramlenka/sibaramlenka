A machine learning-based placement readiness and career guidance application built with Python and Streamlit.

- Predicts placement probability using student and career-related features.
- Includes preprocessing, scaling, and model evaluation steps.
- Provides strength analysis, personalized career suggestions, and a what-if improvement simulator.
- Tech stack: Python, Pandas, NumPy, Scikit-learn, Streamlit, Matplotlib.

Repository: https://github.com/sibaramlenka/PlacementPro_AI

### 2) Driver Drowsiness Detection

A real-time computer vision project to detect fatigue or drowsiness during driving.

- Uses OpenCV and Dlib for face and eye detection.

- Includes a real-time alert mechanism for monitoring.
- Tech stack: Python, OpenCV, Dlib, NumPy.

Repository: https://github.com/sibaramlenka/driver-drowsiness-detection
